# The hazard ratio is awaited for six months after readout

A trial's effect-size forecast is scored only if a hazard ratio for its scored endpoint becomes public within six months of its readout; otherwise it is recorded as missing. In the traced sample 13 of 45 first disclosures carried a hazard ratio and 30 of 45 had one within six months. Waiting indefinitely would capture more but leave the analysis open-ended, and the trials that never publish a number are more often negative, so missing values are handled in a pre-registered sensitivity analysis and never dropped silently.

The hazard ratio scored is the first one reported for the scored endpoint, even when a more authoritative source later reports another. This is a deliberate exception to ADR-0008, which lets the most authoritative source decide whether the trial was positive: the first reported estimate is the pre-specified primary analysis, while later papers often carry updated analyses with longer follow-up.
