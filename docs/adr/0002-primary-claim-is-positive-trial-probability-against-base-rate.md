# The registered primary claim is the Span forecaster against the base rate

The single pre-registered hypothesis is that the Span forecaster's probability of a positive trial scores better than the base rate of each trial's reference class (sponsor type by endpoint type, fixed at registration). A flat overall rate of about 43% would be an easier bar, but industry trials run near 57% positive, so a reviewer would discount a win against it; the flat rate is reported alongside. The hazard-ratio forecast is the part nobody has published and leads the paper's framing, but it is the named key secondary: it resolves months later, on fewer trials, with a tilt toward positive results, and the expected sample cannot power it. If the Span forecaster loses while a frontier model as shipped wins, that is reported as a secondary result.
