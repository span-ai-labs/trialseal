# Trials disclosed only in another language are included

Sponsors that announce results only in Chinese or another non-English language stay in the study. In the traced sample about a fifth of first disclosures came through Hong Kong or Shanghai exchange announcements, so excluding them would shrink the sample and skew it towards Western sponsors. Both adjudicators see the original announcement and a translation, each trial is tagged with its disclosure language, and a sensitivity analysis reruns the result without them.
