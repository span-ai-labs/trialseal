# The scored endpoint is the first time-to-event primary endpoint listed

Where a trial lists several primary endpoints, the scored endpoint is the first one that is time-to-event, not simply the first listed. The interview settled on "the first listed", but in 230 of 2,422 candidates (157 industry-led) the first-listed primary endpoint is a response rate or a safety measure, mostly in combined phase 2/3 records, and those have no hazard ratio to score. Passing over them keeps every candidate scoreable. The alternative is to exclude such trials from the effect-size analysis. This changes what gets registered, so it needs the study lead's confirmation before the protocol is written.
